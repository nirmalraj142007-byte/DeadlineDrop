DeadlineDrop

Help measure fairness — consent text, version v1

DeadlineDrop locks the time of your submission before your file travels, using a hash commitment, so a slow connection cannot make an on-time submission late. We are measuring whether that is true in practice. You may help by sharing a few numbers. It is entirely optional.

What is collected

  • How fast your file uploaded (megabits per second).
  • The size of the file you submitted.
  • When you clicked Submit, relative to the deadline.
  • How long your browser took to fingerprint the file (its SHA-256).
  • The network type you choose in the list (Hostel Wi-Fi, Mobile data, Home broadband, Campus LAN or Other).

Your file contents, name and your own identity are not part of this measurement.

How it is stored and used

  • The numbers are stored under an anonymous id, not your name or email.
  • They are used only to evaluate this project.
  • They are never shown to the teacher per student.
  • They are deleted or aggregated by 26 Nov 2026.

If you do not consent

Submitting works exactly the same without consent. Nothing is sent, and your submission, its time lock and its receipt are not affected in any way.
